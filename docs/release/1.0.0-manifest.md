## Histórico preservado

`d412d1dd0599b9a6f75656daeee1a7e32a010edf`) e recebeu o hotfix de `nanoid` da
PR #100 (`fe3cd357b7b37f3ee72b63af7f91cfb8b5bdf86f`). Esses marcos continuam
úteis para investigação, mas não substituem o SHA final publicado acima. A
[execução #352](https://github.com/Lucasegg/banco-de-solucoes/actions/runs/32739035895),
que encontrou a dependência vulnerável, é evidência histórica de falha, não um
gate aprovado.

## Rollback

Não há rollback automático. Pause merges, preserve runs e diagnósticos,
identifique o último SHA comprovadamente saudável e abra PR com
`git revert <sha-instavel>`, sem reescrever `main`. Reexecute CI e Production
Preflight; depois da publicação, valide o smoke somente leitura. Migration já
aplicada nunca é apagada ou revertida destrutivamente: quando necessário, use
uma migration compensatória revisada.

Este manifesto não contém valores de secrets, tokens, chaves privadas ou
credenciais administrativas.
